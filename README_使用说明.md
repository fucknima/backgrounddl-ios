# 后台下载 BackgroundDL — 浏览器 + 灵动岛版

## 功能

- 内置 WKWebView 打开普通 HTTPS 分享网页；网页登录、网页按钮与下载响应由原生 App 处理。
- 可接管的 HTTPS GET 下载交由后台 URLSession 下载；切到其他应用和锁屏时，系统可继续传输。
- 支持暂停、继续（依赖服务器允许恢复下载及有效 resumeData）、取消、重试、断电重开后后台任务关联。
- 支持多个下载任务，写入本机 `Documents/Downloads`，可从「文件」App 访问。
- 下载期间可创建一条 Live Activity：锁屏显示进度；支持灵动岛紧凑、最小及展开视图。
- 提供自制 App 图标，SwiftUI 原生玻璃材质、圆角控件，使用新 Xcode SDK 获得新系统原生外观。

## 限制（重要）

1. 背景 URLSession 的传输与 Live Activity 刷新是**不同机制**。iOS 挂起 App 后，即使下载继续，系统不承诺持续唤醒 App 提供每一段字节的回调，因此灵动岛进度可能暂时保持上次值，完成后系统唤醒时才更新。
2. WebKit 可以接管的普通下载请求才可以交给 URLSession。`blob:`、`data:`、页面 JS 生成文件、POST 等流程不保证可转移；登录 Cookie、限时下载令牌、服务器反爬或续传限制可能导致失败。
3. 手动从多任务界面强制关闭 App 后，iOS 通常会取消后台 URLSession 的传输。
4. `resumeData` 并不保证每个服务器都能断点续传。服务器不支持 Range、token 过期、文件变化时只能重新下载。
5. 公开仓库**不要提交账号密码、Cookie、分享令牌或签名证书**。

## 构建

在 GitHub Actions 的 Build BackgroundDL iOS IPA 中下载 `BackgroundDL-unsigned` Artifacts；其中是未签名 IPA，需自行签名后安装。
工作流使用 GitHub `xcode-27` public preview runner（可用性由 GitHub 决定）。

## 使用

1. 打开「浏览器」，在地址栏粘贴 HTTPS 分享页面；必要时在网页中登录。
2. 点击网页的「下载」。可接管任务进入下载列表。
3. 返回「下载」查看任务进度，切出 App 或锁屏。
4. 打开 iOS 设置，允许本 App 的实时活动。带灵动岛设备会显示紧凑进度。文件 App → 在我的 iPhone 上 → 后台下载 → Downloads。

## 验证计划

实际 Xcode 编译通过不等于真机网络场景都已通过。应分别测试 10GB+ HTTP Range 服务器、下载中锁屏、Wi-Fi→蜂窝网络切换、恢复下载、签名 URL 过期、低存储空间和后台完成后唤醒 App。


## 1.2 界面与任务统计

- 浏览器页：紧凑地址栏 + 完整网站视图 + 底部轻量导航工具。
- 下载列表优先显示任务；HTTPS 直链入口折叠。
- 前台通过 URLSession 进度回调计算移动平滑速度与 ETA，暂停恢复时重新取基准，避免巨大速度尖峰。
- 锁屏和灵动岛显示最近一次进度、速度/ETA 和上次更新的相对时间。
- iOS 挂起 App 时无法保证持续更新 Live Activity；系统传输可继续，但速度/ETA 可能暂时停留在上一次回调。
- 19GB 等大文件务必留足空间且不要强制杀掉 App；不保证所有服务器的断点续传支持。

## 1.3（构建号 4）任务管理与深色模式

- 下载条目右侧的 **···** 菜单：支持取消并移除运行中任务；支持仅删除列表记录（已完成文件仍保存在「文件」App）；支持将完成文件与记录一起删除；支持重命名已完成文件与分享文件。
- 下载页右上角的 **···**：支持批量清理已完成任务，可选择只清理记录或连文件一起清理。每次删除都有确认，避免误删。
- 浏览器工具栏、地址栏和页面外观跟随 iOS 深浅色；网站提供 `prefers-color-scheme` 时优先使用网站主题。
- 浏览器底部 **··· → 深色模式下强制网页变暗**：对于不支持深色的网站，可尝试添加深色底色和文字样式；该兼容模式可能影响某些网页，请按需关闭。
- `Assets.xcassets/AppIcon.appiconset` 增加 1024px 深色图标；主屏幕图标外观的暗色/自动模式由 iOS 控制，不与网页主题开关绑定。
- 下载数据结构未重置，升级保留现有记录；仍在下载的大文件请等完成后再覆盖安装，避免系统后台任务被安装过程打断。


## 1.4 智能网页深色模式修复

- 修复系统深色模式下百度等站点仍大面积显示亮白背景的问题。
- 现在菜单的默认选项为「智能深色（推荐）」，仅在系统深色且网页背景实际偏亮时自动转换。
- 可在浏览器右下角「···」切换「智能深色」「始终深色」「网站原样」，无需重新下载。
- 采用 WKUserScript 在网页开始加载时注入样式逻辑；对图片、视频、画布、SVG 做颜色补偿，不以简单覆盖 body 背景代替全页面处理。
- 强制转换可能影响某些网页颜色或兼容性；遇到特殊页面可选择「网站原样」。
- 仅改变网页显示，不更改下载 Cookie、后台 URLSession、任务数据库和现有下载路径。
- 网页子框架、CSS 背景图片等少数场景可能无法完美恢复原色；此项需要真机确认。


## 1.5 · 系统分享菜单与紧凑下载列表

- 从 Safari 或其他支持 iOS 分享链接的 App，点击分享，选择「后台下载」。分享扩展会保存 URL 到共享收件箱；打开主 App 后会自动转到浏览器并加载该网址。普通网页仍需在页面中点击下载，不会直接误把 HTML 当作文件。
- 下载页不再堆大卡片：使用系统原生紧凑任务行、细进度条、筛选控件；长按/左滑/··· 管理下载；删除记录默认保留已下载文件。
- 新增 Share Extension：`BackgroundDLShareExtension.appex`，必须与主 App、灵动岛扩展一起签名。
- **签名特别注意**：主 App 和 Share Extension 必须来自同一 Apple 开发团队，且都启用 App Group `group.com.example.backgrounddl.shared`，需要在开发者后台登记并配置两个标识符的配置描述文件。单纯重签 IPA、但签名不含此 App Group 权限时，可能无法安装，或系统分享虽然显示但数据不能交给主 App。
- iOS 不保证分享扩展可以直接唤醒主 App。因此本版本在分享完成后提示打开主 App 接收链接，不采用违规的私有 API 强制跳转。

## 1.6 · 浏览器主页与同名下载自动重命名

- 浏览器底部新增“主页”图标：一键回到 App 内部的起始页面，不访问第三方站点，也不清除浏览器 Cookie。
- 新任务加入下载队列时会检查当前任务名及 Downloads 文件夹已有文件，自动添加数字后缀，如 `mirror.rar`、`mirror (1).rar`、`mirror (2).rar`。
- 下载结束时继续校验实际保存路径；遇到服务器提供新的文件名也不会覆盖同名文件。已完成的下载条目显示最终文件名。
